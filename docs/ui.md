# 화면 설계 (UI/UX)

> PasswordManager의 화면 구성·흐름·컴포넌트 설계 문서.
> 아키텍처·보안 결정은 [`design.md`](./design.md), 의사결정 로그는 [`tradeoffs.md`](./tradeoffs.md) 참고.

## 1. 디자인 기준

| 항목 | 내용 |
|---|---|
| 플랫폼 | Windows 10/11 데스크톱 (WPF) |
| 스타일 | **WPF-UI (Fluent / Windows 11 룩)**, 라이트·다크 테마 지원 |
| 패턴 | MVVM (View ↔ ViewModel 분리) |
| 창 구조 | **단일 창 3-pane** (좌 태그 · 중 목록 · 우 상세) — `design.md` 8장 |
| 최소 창 크기 | 예: 900 × 600 (좁아지면 좌측 태그 pane 접힘) |

## 2. 공통 규칙 (모든 화면 공통)

- **비밀번호는 기본 마스킹**(`••••••`). [보기]를 눌러야 표시되며, 표시 전 **OTP 게이트**를 통과해야 한다(TD-004).
- **지연 복호화**: 값은 [보기] 통과 순간에만 복호화해 표시하고, 곧 다시 가린다.
- **복사** 버튼 → 클립보드에 복사 후 **20초 뒤 자동 삭제**, "복사됨 · 20초 후 삭제" 토스트 표시.
- **위험 동작**(삭제, 평문 내보내기, 마스터 비번/복구 키 변경)은 **확인 다이얼로그** 필수.
- **자동 잠금**: 유휴 시간 초과·창 최소화 복귀 시 잠금 화면으로 복귀.
- **접근성**: 전체 키보드 내비게이션, 포커스 링 표시, 명도 대비 확보, 스크린리더 라벨.
- **에러 표기**: 인라인 메시지 우선(입력 필드 아래), 시스템 오류는 다이얼로그.

## 4. 화면 상세

### S1. 잠금/로그인

```
┌──────────────────────────────────────────────┐
│                                                │
│                 🔒  PasswordManager            │
│                                                │
│        마스터 비밀번호                           │
│        ┌────────────────────────────┐  [👁]    │
│        │ ••••••••••                  │          │
│        └────────────────────────────┘          │
│                                                │
│                 [   잠금 해제   ]                │
│                                                │
│        비밀번호를 잊으셨나요?  → 복구(S8)         │
│                                                │
└──────────────────────────────────────────────┘
```

- 엔터로 제출, 실패 시 필드 아래 인라인 에러.
- **실패 원인 구분(design 5.3)**: "비밀번호가 올바르지 않습니다"(DEK 언래핑 실패) vs
  "파일이 손상되었습니다 → 복구 안내"(본문 태그 실패)를 다르게 표시 → 후자는 S9로.
- 잠금(자동 잠금) 상태도 이 화면을 재사용.

### S2. 최초 설정 마법사

앱을 **처음 실행**할 때(볼트 파일 없음) 1회 진행. 3단계 + 완료. 상단에 진행 표시(1·2·3), 각 단계는
완료 조건을 만족해야 [다음]이 활성화된다. 중간 이탈 방지 — 마법사를 끝내야 볼트가 생성된다.

```
  ①━━━━━②━━━━━③        진행 표시
 비번   복구키  OTP
```

**Step 1 — 마스터 비밀번호 설정 (design 5.6 / TD-009)**

```
┌──────────────────────────────────────────────┐
│  ①  마스터 비밀번호 만들기                       │
│                                                │
│  이 앱을 여는 유일한 열쇠입니다. 잊으면 복구 키가   │
│  필요합니다. 길게 만들수록 안전합니다.             │
│                                                │
│  비밀번호        ┌──────────────────┐  [👁]     │
│                 └──────────────────┘           │
│  강도  ▮▮▮▮▮▯▯▯  (길이 기준)                     │
│  확인            ┌──────────────────┐           │
│                 └──────────────────┘           │
│                                                │
│  · 최소 12자 이상            [🎲 생성기로 만들기] │
│  ⚠ 너무 흔한 비밀번호입니다 (해당 시)             │
│                                                │
│                         [ 다음 → ]              │
└──────────────────────────────────────────────┘
```
- 하한 **12자 미달** 또는 **흔한 비번 차단목록** 해당 시 [다음] 비활성 + 인라인 경고.
- [생성기로 만들기] → 패스프레이즈 모드 권장(외우기 쉬운 긴 비번).
- 강도 막대는 **길이 기반**(참고용, 외부 라이브러리 없음).

**Step 2 — 복구 키 발급 (design 5.7 / TD-010)**

```
┌──────────────────────────────────────────────┐
│  ②  복구 키를 안전하게 보관하세요                 │
│                                                │
│  마스터 비밀번호를 잊었을 때 쓰는 비상 열쇠입니다.  │
│  화면·앱에는 저장되지 않으니 반드시 밖에 보관하세요. │
│                                                │
│   ┌────────────────────────┐   ┌──────────┐    │
│   │ K7F2-9QX4-M1P8-3RTB-... │   │  ▚▞ QR   │    │
│   └────────────────────────┘   └──────────┘    │
│        [📋 복사]  [🖨 인쇄/PDF]                   │
│                                                │
│  ☐ 복구 키를 안전한 곳에 보관했습니다.            │
│                                                │
│                [ ← 이전 ]   [ 다음 → ]           │
└──────────────────────────────────────────────┘
```
- **보관 확인 체크박스**를 켜야만 [다음] 활성(TD-010: 무조건 발급 + 보관 확인).
- 복구 키는 **평문 저장 안 함** — 이 화면을 벗어나면 다시 볼 수 없음을 안내(재발급은 설정 S7에서).

**Step 3 — OTP(2FA) 등록 (design 5.4)**

```
┌──────────────────────────────────────────────┐
│  ③  휴대폰 인증 앱 연결 (선택 열람 보호)           │
│                                                │
│  Google Authenticator 등으로 아래 QR을 스캔하세요. │
│                                                │
│              ┌──────────────┐                  │
│              │    ▚▞ QR     │   [키 수동 입력]   │
│              └──────────────┘                  │
│                                                │
│  스캔 후 표시된 6자리 코드 입력                    │
│              ┌───────────┐                     │
│              │ _ _ _ _ _ _│                     │
│              └───────────┘                     │
│                                                │
│                [ ← 이전 ]   [ 완료 ]            │
└──────────────────────────────────────────────┘
```
- **폰이 앱 화면의 QR을 스캔**하는 방향(앱→폰, design 5.4 주의).
- 6자리 코드가 **검증되어야 [완료]** 활성 → 잘못 등록 방지.
- 완료 시 볼트 파일 생성 → **S3 메인**으로 진입.

> **열림 순서 주의**: Step 1에서 정한 마스터 비번으로 KEK를 만들고, Step 2의 복구 키로 DEK를 한 번 더
> 감싼다(이중 래핑). 즉 **Step 1·2가 끝나야 볼트를 안전하게 만들 수 있다**(design 5.2).

### S3. 메인 (3-pane)

```
┌────────────┬─────────────────────────────┬───────────────────────────┐
│  태그       │  [🔍 검색           ]        │  상세                      │
│            │                              │                           │
│ • 전체      │  ▼ Steam                     │  Steam · 메인              │
│ • 게임      │     ├ 메인   id: myid        │  ─────────────────────    │
│ • 사이트    │     └ 부캐   id: sub@ex.com  │  URL   https://store...   │
│ • 회사      │  ▼ Google                    │  아이디 myid       [복사]  │
│ • + 태그    │     └ 회사   id: me@corp...  │  비밀번호 ••••••  [보기][복사]│
│            │  ▼ 은행                       │  태그  #게임 #메인          │
│            │     └ 개인   id: myid         │  메모  ...                 │
│            │                              │  마지막 변경 2026-04-01     │
│            │                              │  [이력 보기(S6)]           │
│            │  [＋ 계정 추가]               │  [편집] [삭제]             │
├────────────┴──────────────────────────────┴───────────────────────────┤
│  🔓 잠긴 상태 아님 · 자동잠금 5분   [⚙ 설정(S7)]        [🔒 지금 잠그기]  │
└────────────────────────────────────────────────────────────────────────┘
```

- **좌(태그)**: "전체" + 태그별 필터. 다중 선택 가능(선택 태그 AND/OR는 추후 결정).
- **중(목록)**: **사이트명으로 그룹핑**, 그룹 안에 계정들(태그로 구분). 검색은 제목/아이디/태그 대상.
- **우(상세)**: 비밀번호는 마스킹 + [보기](OTP 게이트) / [복사](자동삭제). [편집]·[삭제]·[이력].
- 하단 상태바: 자동잠금 남은 시간, 설정, 즉시 잠금.

### S4. 계정 추가 / 편집

메인(S3)의 [＋ 계정 추가] 또는 상세의 [편집]에서 진입. **오른쪽 패널** 또는 모달 다이얼로그로 표시.
추가·편집 공용 폼(제목만 다름). 필드는 `design.md` 6장·TD-011 기준.

```
┌───────────────────────────────────────────────┐
│  계정 편집                             [✕]      │
│                                                 │
│  사이트명 *   ┌───────────────────────────┐     │
│              │ Steam                       │     │
│  URL         ┌───────────────────────────┐     │
│              │ https://store.steampowered..│     │
│  아이디 *     ┌───────────────────────────┐     │  ← 문자/이메일 겸용
│              │ myid                        │     │
│  비밀번호 *   ┌────────────────┐ [👁][🎲]  │     │  🎲=생성기
│              │ ••••••••••      │            │     │
│  태그        [#게임 ✕] [#메인 ✕]  [＋ 태그]  │     │  ← 여러 개
│  메모        ┌───────────────────────────┐     │
│              │                             │     │
│              └───────────────────────────┘     │
│                                                 │
│  (편집 시) 마지막 변경 2026-04-01 · [이력(S6)]   │
│                                                 │
│                      [ 취소 ]   [ 저장 ]         │
└───────────────────────────────────────────────┘
```

- `*` 필수: 사이트명·아이디·비밀번호. URL·메모·태그는 선택.
- **아이디는 문자/이메일 겸용 한 칸**(형식 구분 없음, TD-011).
- **태그**: 기존 태그 자동완성 + 새 태그 입력, 여러 개 부여.
- **편집 시 비밀번호 필드**: 기본 마스킹. [👁]로 볼 때 **OTP 게이트(S5)** 통과 필요(지연 복호화).
- **저장 시**:
  - 새 계정 → `createdAt`/`updatedAt`/`lastChangedAt` 기록.
  - 편집에서 **비밀번호가 바뀌면** → 이전 값을 `passwordHistory`에 적재하고 `lastChangedAt` 갱신(design 7.2).
  - 비밀번호 외 필드만 바꾸면 이력 적재 없이 `updatedAt`만 갱신.

**비밀번호 생성기 ([🎲])** — `design.md` 7.1

```
┌─────────────────────────────────────────┐
│  비밀번호 생성기                           │
│  모드:  (●) 랜덤   ( ) 패스프레이즈         │
│                                           │
│  ┌─ 미리보기 ──────────────────────┐      │
│  │  gX7$mQ2!vР9wLz                 │ [🔄]  │
│  └────────────────────────────────┘      │
│  강도 ▮▮▮▮▮▮▮▯                            │
│                                           │
│  길이   [────●────]  20   (8~64)          │
│  ☑ 대문자  ☑ 소문자  ☑ 숫자  ☑ 기호        │
│  ☑ 혼동 문자 제외 (0/O, l/1 …)            │
│                                           │
│              [ 취소 ]   [ 적용 ]           │
└─────────────────────────────────────────┘
```
- **랜덤 모드**: 길이 슬라이더(8~64), 문자 종류 토글, 혼동 문자 제외, 강도 표시, [🔄 재생성].
- **패스프레이즈 모드**(토글 시): 단어 수·구분자 선택, "외우기 쉬운 긴 비번" 생성.
- **[적용]** → 위 폼의 비밀번호 칸에 채움. 난수는 CSPRNG(`RandomNumberGenerator`) 사용(design 7.1).
- 최소 1개 문자 종류는 항상 켜져 있어야 함(모두 끄면 [적용] 비활성).

### S7. 설정 (모듈)

메인(S3) 하단 [⚙ 설정]에서 진입. **좌측 섹션 목록 + 우측 내용**의 설정 화면. 부가 기능의 편입 지점(design 7.9).

```
┌──────────────┬──────────────────────────────────────────────┐
│ 설정          │  알림 (슬랙)                                  │
│              │  ──────────────────────────────────────       │
│ · 보안·계정   │  슬랙 알림           [ OFF ⬤   ]              │
│ ·〉알림(슬랙) │  ⚠ 오프라인 모드가 켜져 있어 비활성입니다      │
│ · 네트워크    │     → [네트워크]에서 해제                     │
│ · 백업·데이터 │                                              │
│ · 정보        │  Webhook URL   ┌────────────────────┐        │
│              │                └────────────────────┘        │
│              │  이벤트   ☑ 잠금해제  ☑ 로그인 실패  ☑ 비번변경 │
│              │  ☐ 사이트명 포함                              │
│              │                                              │
│              │  메시지 폼  ┌──────────────────────────┐      │
│              │            │ 🔓 {이벤트} · {시각}       │      │
│              │            └──────────────────────────┘      │
│              │  변수: {이벤트} {시각} {기기명}  [기본값 복원]  │
│              │  미리보기: 🔓 볼트 잠금 해제됨 · 2026-07-29 …   │
│              │                              [ 저장 ]         │
└──────────────┴──────────────────────────────────────────────┘
```

**섹션 구성 (design 7.9)**

| 섹션 | 내용 |
|---|---|
| 보안·계정 | 마스터 비번 변경(S: 현재 비번 확인 후), 복구 키 재발급, OTP 재설정, 자동잠금 시간, 클립보드 삭제 시간 |
| 알림(슬랙) | on/off, Webhook URL, 이벤트 토글, 사이트명 포함, **메시지 폼(변수 템플릿)** |
| 네트워크 | **전역 오프라인 스위치**(기본 ON=차단) |
| 백업·데이터 | 백업/복원, 가져오기/내보내기(평문은 경고 다이얼로그) |
| 정보 | 앱 버전, 볼트 파일 위치 |

- **전역 오프라인 스위치(네트워크, TD-013)**: 기본 **차단**. 차단 상태면 **알림(슬랙) 섹션이 비활성(회색)** +
  "오프라인 모드 해제 필요" 안내. 슬랙을 켜려면 네트워크 섹션에서 먼저 해제(2단).
- **메시지 폼(TD-014)**: 허용 변수(`{이벤트}`/`{시각}`/`{기기명}`)만 치환. 그 외 `{…}`는 리터럴 출력.
  **미리보기**로 실제 전송 문구 확인, **[기본값 복원]** 제공. secret 변수는 목록에 없음(구조적 차단).
- **위험 동작**(마스터 비번/복구 키 변경, 평문 내보내기)은 확인 다이얼로그 필수(2장).
