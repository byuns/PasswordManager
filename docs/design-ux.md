# 디자인 · UX 리모델링

기능 완료(M1~M5 + 백업/복원) 후, [[feedback-ui-polish-last]] 원칙에 따라 외형을 일괄 정비한다.
근거 결정은 `tradeoffs.md`(TD-023)에, 기능 설계는 `design.md`에 있다.

## 1. 방향

- **범위**: 네비게이션까지 재설계 (사이드바 도입) + 카드 리스트 + 디자인 토큰 일관화.
- **기반**: WPF-UI(Fluent, Dark). 기존 클래식 `ListView`/`GridView`가 테마를 안 따라 흰 배경으로
  렌더되던 문제(다크/화이트 혼재)를 근본 해결한다.
- **강조색(accent)**: **인디고 `#6366F1`** (현대·차분·세련). 시스템 기본 시안을 대체.

## 2. 셸 구조 — 두 모드

셸(`ShellViewModel`)은 상태에 따라 두 가지 레이아웃을 가진다.

| 모드 | 화면 | 사이드바 |
|---|---|---|
| **잠금(Locked)** | 새 볼트 생성 · 로그인 · 복구 | ❌ 없음. 중앙 정렬 카드, 풀스크린(첫인상) |
| **열림(Open)** | 항목 · 설정 · 정보 | ✅ 왼쪽 `NavigationView` 레일 |

## 3. 열림 모드 — 사이드바(`ui:NavigationView`)

```
┌──────┐ ┌──────────────────────────────────┐
│ 🗝 항목│ │ 검색 [.................]  [+ 새 항목]│
│ ⚙ 설정│ │ ┌──────────────────────────────┐ │
│ ℹ 정보│ │ │ 🅰  제목 (굵게)      2026-07-30 │ │
│      │ │ │     아이디 (보조색)  [보기][편집]│ │
│──────│ │ └──────────────────────────────┘ │
│ 🔒잠금│ │ ┌──────────────────────────────┐ │
└──────┘ │ │ 🅱  ...                        │ │
         └──────────────────────────────────┘
```

- **🗝 항목**: 검색 + `새 항목`(Primary) + **카드 리스트**.
- **⚙ 설정**: 현재 상단 툴바에 몰려 있던 보조 동작을 이전 —
  OTP 등록/재설정 · 마스터 비밀번호 변경 · 자동잠금 시간 · 클립보드 삭제 시간 · 백업/복원.
  → M6 3단계 "설정 화면(S7, design 7.9)"의 토대. 이후 슬랙 알림 섹션도 여기 얹는다.
- **ℹ 정보**: 앱 버전 · 볼트 파일 위치(design 7.9 "정보" 섹션).
- **🔒 잠금**: 레일 하단 고정.

> 상단에 버튼 7개가 난립하던 문제를 사이드바로 분산해 해소한다.

## 4. 카드 리스트 (항목)

- 항목 하나 = 카드 하나. 구성: **사이트 이니셜 아바타** · **제목(굵게)** · **아이디(보조색)** ·
  우측 **마지막 변경일** + 액션(**보기 · 편집 · 삭제**).
- 비밀번호·이력은 카드에 노출하지 않는다(열람은 OTP 게이트, design 5.4·TD-004 유지).
- 선택/호버 시 강조색 테두리·은은한 배경 변화.

## 5. 디자인 토큰

- **여백 스케일**: 4 · 8 · 12 · 16 · 24 (px).
- **타이포**: WPF-UI `TextBlock` FontTypography (Title / Subtitle / Body / Caption).
- **카드**: 모서리 반경 8, 은은한 테두리(`CardBackground`/`ControlStroke`), 호버 강조.
- **색**: 배경/표면/텍스트는 WPF-UI Dark 토큰(`ApplicationBackground`, `CardBackground`,
  `TextFillColorPrimary/Secondary`)에 의존. 강조만 인디고로 오버라이드.

## 6. 진행 순서(화면별, 단계마다 확인)

1. **강조색·전역 토큰** 적용 (App.xaml 리소스) — 시각 기반 마련.
2. **셸 레이아웃**: 잠금/열림 두 모드 + `NavigationView` 뼈대(항목/설정/정보/잠금).
3. **항목 화면**: 카드 리스트로 교체(클래식 ListView 제거).
4. **설정 화면(S7)** 신설 — 보조 동작 이전(3단계 기능작업과 합류 지점).
5. **정보 화면** + 잠금 상태 화면(생성/로그인/복구) 정돈.
6. 앱 실행 스크린샷으로 확인.

각 단계는 완료 후 사용자 확인을 받고 다음으로 넘어간다(CLAUDE.md).
